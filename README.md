# 股票策略大全

## 策略1:追主线热点
* 找出当前市场热点主线以及周边买入拿好
```
例如买入AI以及AI相关股票
```

## 策略2:追次新股
* 找出科创板次新股寻找可能继续大涨的股票买入
```
688开头的股票比较牛逼要找次新股就找这种
```

## 策略3:抄底情绪杀股票
* 例如打仗石油暴涨就买入暴涨后会影响暴跌的股票买入
```
例如分批减仓航空股，等油价反弹稳定，大概率营收卖出做中短线投资
```

## 策略4:价值投资买入分红高股票
* 例如买入招商银行，中国神华，长江电力等
```
买入持有做t，持续拿分红
```

## 策略5:哪个指数基金
* 例如买入上证etf，创业板etf，科创版etf
```
当大盘暴跌时，猛干指数etf，越跌越买，
疯狂加仓干，等指数回来，你就发财了
```
